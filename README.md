### How to run in your server
1. `token.txt`에 디스코드 봇 토큰을 복붙
2. 예시를 참고해 `db.json`을 설정
3. `main.py`를 실행 (실행할 때 `main.py` 안에 있는 `dbgChannel`은 가지고 계신 디버그용 서버의 로그용 채널 ID로 바꿔주세요.)
----
1. `token.txt`にDiscordボットのトークンをコピペ
2. 例を参考にして`db.json`を作成
3. `main.py`を起動（`main.py`の中の`dbgChannel`は自分のデバッグ用サーバーのログ用チャンネルのIDに変更してください。）
----
1. Paste token of Discord Bot into `token.txt`
2. Write `db.json`.
3. Run `main.py`. Please change `dbgChannel` of `main.py` to ID of your server's log channel.
